# Security Policy

## Supported Versions

The following versions are currently being supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| v3      | :white_check_mark: |
| < v3    | :x:                |

## Reporting a Vulnerability

To report a vulnerability, please submit an advisory [here](https://github.com/SeitaBV/timely-beliefs/security/advisories).

We will get back to you within a week. If we accept the advisory, you will be credited as reporter.
